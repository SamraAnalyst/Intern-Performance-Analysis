# 📊 Intern Performance Tracking Dashboard

An enterprise-grade analytics dashboard built using Microsoft Excel to evaluate organizational intern cohort output, department workloads, and task closure metrics.

## 🖼️ Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## 🛠️ Key Analytical Indicators
* **Workload Extraction:** Evaluated total capacity distributions across Data Analytics, Data Science, and Marketing modules.
* **Completion Analysis:** Programmed relative metric tracking calculations (TasksCompleted / TasksAssigned) to audit structural task closure drop-offs.
* **HR Metrics Automation:** Implemented Pivot processing charts to automate departmental performance evaluations.
